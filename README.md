# 캡차 (CapCar)

주행 중에는 화면 없이 음성으로 "지나친 장소"와 "차량 이상 증상"을 캡처하고, 주차(P)하면 카드와 정비 리포트로 정리해 보여 주는 차량용 앱입니다.

## APK 위치

`apk/캡차_캡차_release.apk`

## 실행 방법

1. Pleos Connect 에뮬레이터를 실행합니다.
2. `adb install -r apk/캡차_캡차_release.apk` 를 실행하거나 APK 파일을 에뮬레이터 창에 끌어다 놓습니다.
3. 앱 목록에서 "캡차"를 실행합니다.
4. 화면 왼쪽의 기어(P, R, N, D)를 눌러 바꿉니다.
   - D: 지도에서 차가 움직이고, 오른쪽 채팅 화면의 "마이크 켜기"를 누르고 말하거나 입력 칸에 적으면 캡처합니다. 예: "방금 오른쪽 빵집 저장해 줘", "글레오, 브레이크 소리 이상해. 캡처해 줘"
   - P: 차가 멈추고, 오른쪽 화면이 오늘 남긴 캡처 카드로 바뀝니다. 카드에서 정비 리포트와 세부 보기로 이어집니다.

소스에서 빌드하려면 JDK 17과 Android SDK(API 34)가 필요합니다.

```
./gradlew releaseApk
```

`apk/캡차_캡차_release.apk` 가 만들어집니다.

## 테스트 환경 및 필요한 설정

| 항목 | 내용 |
|---|---|
| Pleos Connect 에뮬레이터 버전 | Pleos Connect 에뮬레이터에서는 아직 실행하지 못했습니다. 일반 Android 에뮬레이터(Android 16, API 36)에서 설치와 실행을 확인했습니다. |
| 화면 규격 | 가로 2400 × 1080 화면에서 확인했습니다. 화면은 가로형 16:9(1920 × 1080) 기준이며 화면 크기에 맞춰 비율을 유지한 채 조절됩니다. |
| 빌드 도구 | Gradle 8.14.3, Android Gradle Plugin 8.11.1, JDK 17 (Android Studio는 사용하지 않았습니다) |
| 최소 지원 버전 | Android API 28 |
| 대상 버전 | Android API 34 |

- 마이크: 에뮬레이터의 Extended controls > Microphone 에서 "Virtual microphone uses host audio input"을 켜고, 앱이 마이크 권한을 물으면 허용합니다.
- 차량 값: 차량용 안드로이드에서는 차량의 속도와 기어를 읽어 화면에 반영합니다. 읽을 수 없는 기기에서는 앱 안의 시뮬레이터 값을 씁니다.
- AI로 말 이해하기(선택): 앱을 켜면 Ollama 서버(에뮬레이터에서는 `http://10.0.2.2:11434`, 브라우저에서는 `http://localhost:11434`)에 자동으로 연결하고, 연결되면 서버의 언어 모델이 말의 뜻을 이해합니다. 연결되지 않으면 앱 안에 정해 둔 규칙으로 이해합니다.
